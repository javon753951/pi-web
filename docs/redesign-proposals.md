# 智擎 · 前端重设计提案（三选一）

> ✅ **已选定并落地：「琉璃玄机 · Glass Console」= 方案 A 骨架 + 方案 C 皮肤**（2025-08，已实现于 `web/`）。
> 结构取 A（40px 细顶栏、底部单行状态条 + 流式波形、LED、高信息密度、折叠零残留），
> 皮肤取 C（冷白渐变桌面、玻璃卡悬浮、金=品牌/主动作、靛=活数据、深色玻璃代码板）。
> 下方 A/B/C 三案保留作为设计备选记录。

> 产品定位：**数字员工控制台** —— 单用户、每会话一个 pi 子进程的 agent 工作台。
> 页面唯一任务：**下达任务并监视 agent 的执行**（流式消息 / 工具调用 / 工作区 / 产物）。
> 风格诉求：智能 · 简约 · 大气。
>
> 三套方案共享同一套**结构修复**（见文末），再各自给出完整视觉身份。

---

## 方案 A「玄机 · Onyx Console」—— 深空仪表，暗色专注

**一句话**：把控制台做成飞行器座舱 —— 一切数据都是仪表读数，唯一会"动"的只有活数据。

暗色但**不是**"纯黑 + 荧光绿"：底色是带蓝相的玄青，文字是暖灰白，唯一的活色是**玉青**。代码块不再是黑岛，而是与主题同世界的深一阶面板 —— 整页一个世界观，没有割裂。

### 色板

| 令牌 | 值 | 用途 |
|---|---|---|
| `canvas` | `#0B0F14` | 玄青底 |
| `surface` | `#11161E` | 面板/侧栏/卡片 |
| `inset` | `#1A2230` | 凹槽：气泡/代码/悬停 |
| `line` | `#232C3B` | 发丝线 |
| `ink` | `#E7ECF3` | 正文 |
| `ink-dim` / `ink-faint` | `#9AA7B6` / `#5C6A7C` | 次级/弱化 |
| `jade`（accent） | `#4AD9C9` | 唯一活色：流式/焦点/遥测 |
| `ok` / `signal` / `alarm` | `#3ECF8E` / `#F0B35C` / `#F2706B` | 状态三色 |

### 字体

- 显示：Space Grotesk 600（标题、会话名、空态大字）
- 正文：系统无衬线（PingFang）
- 数据：JetBrains Mono —— **所有标签、读数值、时间、计数全部等宽**，仪器感拉满

### 布局

```
┌──────────────────────────────────────────────────────────────┐
│ ◉ 智擎   聊天 | 技能广场              ● 运行中 · claude-opus  │ ← 40px 细顶条
├────────┬─────────────────────────────────────────┬───────────┤
│ 会话    │   思考过程 ▸（折叠=零残留）               │ 文件 | 产物│
│ ● 项目A │   ┌────────────────────────────┐        │ ▾ src/    │
│ ● 项目B │   │ bash ✓ 1.2s  (同底色深阶面板) │        │ ▾ server/ │
│ ○ 项目C │   └────────────────────────────┘        │ ▾ web/    │
│        │   消息正文 markdown…                       │  ───────  │
│        │   ░░ 正在思考 ░░                           │ 产物列表  │
├────────┴─────────────────────────────────────────┴───────────┤
│ ● claude-opus · thinking:high   ▁▂▃▄▅▆▇▆▅▄▃▂▁   12 条 · ws ✓ │ ← 28px 状态条
└──────────────────────────────────────────────────────────────┘
```

- 顶栏从 52px 瘦身到 **40px**：只留品牌、视图切换、会话状态。遥测读数全部下放到底部状态条。
- **底部新增 28px 单行状态条**（VSCode 式）：左 = 会话 LED + 模型 + thinking 级别；中 = 流式时等宽波形动画 `▁▂▃▄▅▆▇`；右 = 消息计数 + 连接 + 版本。整条可折叠，折叠后**零残留**。
- 圆角收敛 8–10px；所有面板 1px 发丝线。

### Signature：单行状态条 + 波形

信息密度分配向 IDE 学习：顶栏极简、底栏承载遥测。流式时波形在状态条上"呼吸"，是全页唯一的持续动画 —— 智能感来自"你在监视一台活的机器"。

### 动效

LED 辉光、波形、面板 200ms 轻升。代码块/工具卡展开 220ms 缓动。reduced-motion 全部降级为淡入。

### 风险与取舍

暗色在强光下可用性下降 —— 单用户自用工具可接受；为此特意选蓝相底色而非纯黑，降低眩光。

## 方案 B「素笺 · Blueprint」—— 冷白工程图纸，亮色精确

**一句话**：把"数字员工平台"当作一张精密工程图纸来画 —— 冷白纸面、靛蓝数据线、可测量的秩序。

刻意避开"暖米 + 衬线 + 赭红"的文艺默认：这里是**冷白 + 群青**的工程师美学。空态英雄区铺 24px 淡蓝图纸网格，代码块做成**晒图纸**（深蓝底、白字、琥珀高亮）—— 全页唯一的深色块，像图纸里贴的一张蓝图。

### 色板

| 令牌 | 值 | 用途 |
|---|---|---|
| `canvas` | `#F6F7F9` | 纸面（铺 24px 淡蓝网格） |
| `surface` | `#FFFFFF` | 面板/卡片 |
| `inset` | `#EFF1F4` | 凹槽/悬停 |
| `line` | `#E2E5EA` | 发丝线 |
| `ink` / `ink-dim` / `ink-faint` | `#171A21` / `#5F6672` / `#8A919C` | 墨色三阶 |
| `ultramarine`（accent） | `#2B59D8` | 数据线/焦点/链接 |
| `ok` / `signal` / `alarm` | `#12A150` / `#D97706` / `#D9382E` | 状态三色 |
| `blueprint`（代码底） | `#16264F` | 晒图纸：白字 + `#E5B567` 琥珀高亮 |

### 字体

- 显示：Space Grotesk 500（标题克制使用）
- 正文：系统无衬线
- 标注：JetBrains Mono 10.5px 大写 —— **一切注解都是图纸上的刻字**（`PJ-01 · AGENT CONSOLE`、`SCALE 1:1`）

### 布局

```
┌──────────────────────────────────────────────────────────────┐
│ ◼ 智擎 · PJ-01 数字员工控制台     [聊天|技能广场]    ● 网关正常 │ ← 48px 图框顶栏
├────────┬─────────────────────────────────────────┬───────────┤
│ 会话档案│  (图纸网格背景)                           │ 工作区图   │
│ ────── │   ◯ 3.14159…                             │ ┌─文件───┐ │
│ ▸ 项目A │   给数字员工下达第一个任务                  │ │▾ src   │ │
│ ▸ 项目B │   ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─            │ │  index │ │
│        │   ↳ 已连接 · 4 个子进程运行中               │ └────────┘ │
├────────┴─────────────────────────────────────────┴───────────┤
│ 会话 a3f9 · running · 4ms     ▁▂▃▄▅▆▇▆▅▄▃▂▁    消息 12 · v0.1.0 │
└──────────────────────────────────────────────────────────────┘
```

- 顶栏带"图框"感：标题用图号式标注；视图切换是无容器文本分段。
- 底部同样配 28px 状态条（三方案共有的信息架构，视觉随主题变）。
- 面板 = 白卡 + 1px 线 + 8px 圆角；空态 = 图纸网格 + 大 π 工程图。

### Signature：虚线引线标注（leader-line annotation）

悬浮/激活任意元素时，一条 200ms 描线动画的虚线引线从元素边缘伸出，缀一行等宽小字：`↳ 会话 #a3f9 · running`、`↳ 工作区 14 files`、`↳ tool: bash · 1.2s`。整页像一本摊开的工程手册 —— "可测量的大气"。

### 动效

仅两处：引线描线（200ms）、展开折叠（220ms）。其余零动画。这是三套里最安静的一套。

### 风险与取舍

引线标注如果做满全页会吵 —— 只保留在：会话项、工具卡、文件树、状态条四类元素上。代码块的晒图纸蓝需要调好语法高亮对比度。

## 方案 C「留白 · Gravity Float」—— 极简大气，亮色仪式感

**一句话**：拆掉所有边框和盒子 —— 结构靠留白与阴影分层，面板像漂浮在空气中的玻璃片。

"大气"的极致是**什么都不画**。背景是极淡的冷白微渐变（带一丝几乎不可见的靛色 tint），面板全部玻璃化（白 80% + 模糊），分隔只用 `rgba(20,25,35,.08)` 的细线。唯一"重"的颜色是**赭金** —— 只出现在品牌字标与主按钮两处，像一枚印章。

### 色板

| 令牌 | 值 | 用途 |
|---|---|---|
| `canvas` | `#EEF1F6 → #E9EDF4` | 冷白微渐变 |
| `surface` | `rgba(255,255,255,.8)` + blur | 玻璃面板 |
| `line` | `rgba(23,26,33,.08)` | 仅分隔用 |
| `ink` / `ink-dim` / `ink-faint` | `#141821` / `#6A7280` / `#9AA1AD` | 墨色三阶 |
| `gold`（品牌） | `#B0892F` | 字标/主按钮/空态 π |
| `indigo`（活数据） | `#3B6EF5` | 流式光标/焦点环 |
| `ok` / `signal` / `alarm` | `#159A5E` / `#C77E1D` / `#D64541` | 状态三色 |

### 字体

- 显示：Playfair Display（**仅两处**：空态巨幅 π 与问候、品牌字标）—— 衬线是仪式感，不是全身
- 正文：系统无衬线
- 数据：JetBrains Mono

### 布局

```
        （无边框 —— 留白即结构，面板与主区 12px 间距悬浮）
┌───────────┐   ┌────────────────────────────────────┐ ┌───────────┐
│  玻璃卡    │   │                                    │ │  玻璃卡    │
│  会话列表   │   │         （大片留白）                 │ │  文件/产物 │
│  ● 项目A  │   │                                    │ │           │
│  ● 项目B  │   │             π                       │ │           │
│           │   │        给数字员工下达第一个任务        │ │           │
│           │   │                                    │ │           │
└───────────┘   │   ╭──────────────────────────────╮  │ └───────────┘
                │   │  输入坞：悬浮玻璃卡，聚焦微升    │  │
                │   ╰──────────────────────────────╯  │
                └────────────────────────────────────┘
```

- 顶栏 56px **纯留白**：只有品牌 + 两个图标按钮，无边框、无分段控件（视图切换移到左栏底部）。
- 中栏消息流 `max-w 780px` 居中，两侧呼吸。
- **Composer = 悬浮输入坞**：底部居中、半径 16px 玻璃卡、阴影漂浮；聚焦时轻微升起 + 焦点环。
- 面板间 12px 间距 + 统一软阴影（`0 1px 2px rgba(20,25,35,.05), 0 8px 24px rgba(20,25,35,.06)`）。

### Signature：悬浮输入坞 + 巨幅空态

空态时中栏是一整片留白：中央 64px 金色 π、一行衬线问候、细线分隔、等宽提示。输入坞像停在玻璃水面上的码头 —— 整页看不到一条可见边框线，结构全凭间距与阴影。

### 动效

只有三个时刻：输入坞聚焦升起（240ms）、抽屉滑入（240ms）、空态 π 淡入。**删除所有入场编排动画** —— 大气的反面是花哨。

### 风险与取舍

信息密度最低 —— 遥测读数必须收进状态条与悬停浮层；这是三套里"最不像工具"的一套，但最符合"大气"。适合你主要在大屏、单人使用的心智。

## 通用修复（三套方案共同落地）

已修复，随任一方案保留：

1. **折叠残留条**：`collapse-inner` 禁止直接加 padding/border（Chrome 计算 0fr 轨道基线时计入 padding 导致折叠后残留 ~17px 内容条）。`ThinkingBlock`、`ToolCallCard` 已改为"外层纯裁剪 + 内层承载样式"，`SessionItem` 原本合规。规范已写入 `index.css` 的 `collapse-grid` 注释。
2. **顶栏溢出**：TopBar 加 `overflow-hidden` + 右组 `min-w-0`，窄窗时读数优雅截断而非"露出框外"。

## 选择建议

| | A 玄机（暗色座舱） | B 素笺（亮色图纸） | C 留白（极简大气） |
|---|---|---|---|
| 情绪 | 专注、夜间、工程师 | 精确、秩序、可测量 | 仪式感、开阔、克制 |
| 信息密度 | 高（IDE 式） | 中高 | 低 |
| 差异化风险 | 中（需避开纯黑+荧光套路） | 低（图纸语言很少见） | 中（留白需要执行精度） |
| 最适合 | 每天长时间写代码的人 | 喜欢"一切尽在掌握"的人 | 看重第一眼气质的人 |

**我的推荐：方案 B**。理由：它是三套里差异化最稳的（图纸语言在同类工具里几乎没有），"智能"来自可测量的秩序，"简约"来自冷白与发丝线，"大气"来自网格与引线标注营造的工程感；同时亮色对你现有的代码/工具卡片改动最小、暗色配色对长时间阅读的负担也最小。
